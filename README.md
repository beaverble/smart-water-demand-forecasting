# 상수도 시간대 수요 예측 (LSTM)

상수도 검침 데이터로 가구별 시간대 물 사용량을 예측하는 LSTM 모델이다.
배수지 운용을 위한 단기(24시간) 예측과 용수 수급 계획을 위한 장기(주간) 예측을 각각 학습한다.
상수도 실증 프로젝트에서 개발한 모델이며, 저장소에는 학습 코드만 담았다. (서비스 연동·API 코드와 데이터는 제외)

<br>

## 모델

- **단기** (`train_short_predict.py`) : 과거 72시간을 입력해 향후 24시간 예측
- **장기** (`train_long_predict.py`) : 주간 사용 패턴으로 향후 7일 예측
- **구조** : LSTM(32) → Dropout → LSTM(32) → Dropout → Dense(24), Adam / MSE

<br>

## 전처리

- 가구(`CUSNUM`)마다 사용량 스케일이 달라, `MinMaxScaler`를 **가구 단위로 따로 fit** 한 뒤 예측값을 역변환
- 요일·월·시간대는 **원-핫 인코딩**, 기상 피처는 스케일링
- 윈도우 생성 시 **가구 경계를 넘지 않도록** `make_dataset`에서 가구별로 끊어서 처리

<br>

## 평가

- 일 합계 기준 **MAPE**로 평가
- 전처리 전에는 단기 MAPE가 100%를 넘었지만, 가구별 스케일링·피처 정리 후 **단기 11%대 / 장기 4~5%대**까지 개선
- 실측 기준이며, 관련 연구는 **ICTC 2023**에서 발표

<br>

## 실행

```
pip install -r requirements.txt
python train_short_predict.py
```

- 입력은 시간별 검침 CSV(`CUSNUM`, `DATE`, `USAGE`, 시간/기상 피처)를 사용한다.
- 데이터는 저장소에 포함하지 않는다.
